- `fluffytail-logo-white.svg`: `FluffyTail_Logo_White.svg`, active brand/logo role, secondary in the additional library.

The original library sources remain unchanged. No working Illustrator artboard or experimental Firefly generation is used here. No proprietary font binary is included. See `docs/fluffytail-brand-ux.md` for asset IDs and verified typography.
